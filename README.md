# Dead Road: Ricochet Evolution V5

## Project Overview
Dead Road: Ricochet Evolution V5 is a browser-based zombie survival game created for AI 101 Project 4.

The player controls a rolling ball on an endless road, destroys zombies and obstacles, collects power-ups, and survives as long as possible.

## How to Run
1. Open the `build` folder.
2. Open `index.html` in Google Chrome or Microsoft Edge.
3. Start the game and follow the on-screen instructions.

No installation or external libraries are required.

## Controls
- Space: Charge and launch the ball.
- W / S: Adjust movement speed.
- A / D: Steer left and right.
- Shift: Activate speed boost.
- Q: Activate Ricochet Rampage.
- R: Restart the game.
- P: Pause the game.
- M: Toggle sound.

## Main Features
- Endless road survival gameplay.
- Continuous forward movement.
- Ten different zombie types.
- Obstacles and changing environments.
- Collision-based combat.
- Ricochet Rampage skill that bounces between enemies and obstacles.
- Skill cooldown system.
- Power-ups that change the ball's appearance and abilities.
- Prism Core collection system: collecting seven cores activates temporary invincibility.
- Health, score, kill count, and combo systems.
- Visual effects, particles, and impact animations.

## Design Process
Cycle 1 focused on creating a simple physics-based ball game.

Cycle 2 explored improvements to gameplay, including continuous movement, enemies, obstacles, and survival mechanics.

The game was later expanded into Ricochet Evolution V5 with additional combat mechanics, upgrades, and visual effects.

## Known Limitations
- Graphics use stylized 2.5D rendering rather than realistic 3D models.
- Physics behavior is simplified.
- Some visual effects may affect performance on slower computers.
- Gameplay balance requires further testing.
- The latest V5 features require separate verification from earlier Cycle 1 and Cycle 2 tests.

## Out of Scope
- Multiplayer gameplay.
- Online accounts.
- Global leaderboards.
- Photorealistic graphics.
- Online save synchronization.
