# AI Use Log — Dead Road: Ricochet Evolution V5

## 1. Tools Used

**AI Tool:** ChatGPT

**Development Tools:** Visual Studio Code (VS Code), GitHub, Google Chrome / Microsoft Edge

**Purpose:** To create, test, improve, and document a browser-based game using AI-assisted development.

## 2. Cycle 1: Initial Physics Ball

**My Contributions:**

- Developed the original idea of a physics-based ball game.
- Selected a third-person camera following the ball.
- Chose a charging launch system using Space.
- Designed the directional controls and physics challenges.
- Used VS Code to organize and manage the project files.

**ChatGPT Contributions:**

- Assisted with the project plan, PRD, and ADR documents.
- Generated the initial HTML, CSS, and JavaScript.
- Helped explain how to create and organize files in VS Code.

**Result:**
The initial game opened successfully in a browser. I tested the basic controls and evaluated the gameplay.

## 3. Cycle 2: Zombie Survival

**My Contributions:**

- Decided the first version was too short and simple.
- Proposed an endless road survival game.
- Requested approaching zombies, obstacles, and collision-based combat.
- Chose continuous forward movement after launching.
- Used VS Code to manage the revised game files and documentation.
- Generated revised game code.

**ChatGPT Contributions:**

- Added zombie spawning, obstacles, collision detection, and survival mechanics.

**Result:**
The revised version introduced continuous gameplay, enemies, obstacles, and a survival system.

## 4. Additional Development: Versions 3–5

**My Contributions:**

- Requested ten different zombie types.
- Changed movement controls to WASD.
- Added Shift for speed boosting.
- Proposed power-ups and collectible items.
- Designed the seven Prism Core collection requirement for temporary invincibility.
- Requested visual upgrades to the ball.
- Proposed Ricochet Rampage, a skill that bounces between enemies and obstacles.
- Requested stronger impact effects, combos, and score animations.
- Used VS Code to edit and organize project files during development.
- Generated the updated game implementations.

**ChatGPT Contributions:**

- Added new combat mechanics, visual effects, and item systems.

**Result:**
Dead Road: Ricochet Evolution V5 became the final selected version. The game was opened successfully, but full verification of all new systems is still required.

## 5. Independent Work in VS Code

In addition to working with ChatGPT, I used Visual Studio Code to manage and edit the project locally.

My work included:

- Creating and organizing project folders.
- Creating and editing Markdown documentation files.
- Managing different versions of the game.
- Copying and replacing HTML files.
- Saving changes and checking the project structure.
- Opening the HTML game in a browser for testing.

ChatGPT provided instructions, while I performed the file management and editing operations in VS Code.

I later transferred the project files to GitHub to organize the final submission.

## 6. Testing and Evaluation

I tested the games in a web browser and reviewed their functionality.

Testing focused on:

- Launching the game.
- Ball movement and directional controls.
- Restart functionality.
- Basic gameplay behavior.

The later versions introduced additional abilities and systems that require separate testing.

Screenshots and documented test results are stored in `build-record/tests/` and `testing-and-failure-log.md` when available.

## 7. Known Limitations

- The game uses stylized 2.5D graphics rather than realistic 3D models.
- Physics behavior is simplified.
- Some effects may affect performance on slower computers.
- Game balance requires additional testing.
- The latest V5 features have not been fully verified through documented tests.

## 8. AI Disclosure

ChatGPT was used extensively throughout the project for coding, planning assistance, design documentation, and revisions.

I developed the original game concept, selected the gameplay mechanics, requested the improvements, evaluated the results, and managed the project files using Visual Studio Code and GitHub.

The game implementation was primarily AI-generated, while the project direction and final creative decisions were made by me.
