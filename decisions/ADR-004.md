# ADR-004: Gameplay Expansion and Visual Improvements

**Status:** Accepted — Additional Development (V3–V5)

**Context:** The earlier versions of Dead Road were too simple and lacked variety, replayability, and satisfying combat feedback. I wanted to create a more engaging survival experience.

**Decision:** I decided to expand the game by adding several gameplay and visual features:

- Changed movement controls to WASD.
- Added Shift for a temporary speed boost.
- Added ten different zombie types with different characteristics.
- Added changing environments, roads, and obstacles.
- Added collectible items and power-ups.
- Added a system where collecting seven Prism Cores activates temporary invincibility.
- Added visual upgrades that change the ball's appearance when powered up.
- Added Ricochet Rampage, a special skill that makes the ball bounce between enemies and obstacles, destroying them.
- Added a cooldown system for special abilities.
- Improved combat feedback with impact effects, particles, screen shake, score pop-ups, and combo animations.

**Consequence:** These changes make the game more varied and visually engaging. However, the additional mechanics increase code complexity and may introduce performance issues or gameplay balance problems.

**AI Use:** I made the creative decisions and requested the new features. ChatGPT generated much of the implementation code, while I used VS Code and GitHub to manage and review the project.

**Testing:** The updated game was opened and reviewed. Some individual features were checked, but complete V5 testing and long-term gameplay balancing remain unfinished.
